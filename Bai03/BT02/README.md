# Bài thực hành 03 - Buổi 02: Tạo Web Server với Node.js

## 1. Yêu cầu bài tập
- Tạo tập tin `bai02.js`.
- Sử dụng module `http` để tạo Web Server chạy tại cổng `3000`.
- Trang chủ (`/`): Hiển thị lời chào và mã sinh viên.
- Trang giới thiệu (`/about`): Hiển thị thông tin giới thiệu bản thân.
- Xử lý lỗi: Trả về mã trạng thái HTTP `404` khi truy cập đường dẫn không tồn tại.

## 2. Hướng dẫn thực thi
Mở Terminal tại thư mục chứa file và chạy lệnh sau:
```bash
node bai02.js
