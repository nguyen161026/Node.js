# Bài thực hành 03 - Buổi 03: Module File System (`fs`) trong Node.js

## 1. Yêu cầu bài tập
- Tạo tập tin `bai03.js` sử dụng module `fs`.
- Tạo tập tin `thongtin.txt` chứa họ tên và mã sinh viên bằng `fs.writeFile()`.
- Đọc và hiển thị nội dung tập tin lên Terminal bằng `fs.readFile()`.
- Ghi nối thêm tên lớp vào cuối tập tin bằng `fs.appendFile()`.
- Đọc lại tập tin để chứng minh nội dung đã được cập nhật chính xác.

## 2. Hướng dẫn thực thi
Mở Terminal tại thư mục chứa file và chạy lệnh:
```bash
node bai03.js
